== Description ==

Prologue is a clean block theme for WordPress. It has a simple, readable layout with a light and a dark style variation, and patterns for a hero section and a call to action.

Posts are easy to scan: sticky posts are highlighted on the blog, comments show avatars with replies indented, and replies from the post's author stand out. Posts split into pages get page links, and images from the classic editor are aligned.

Everything is styled through the Site Editor, so you can change colors, fonts and layouts under Appearance > Editor without touching code.

== Installation ==

1. In your admin, go to Appearance > Themes and click Add New Theme.
2. Click Upload Theme and choose the theme's zip file.
3. Click Install Now, then Activate.

== Frequently Asked Questions ==

= How do I switch to the dark style? =

Go to Appearance > Editor > Styles, choose Dark, and click Save.

= How do I change the "Featured" label on sticky posts? =

Use the `prologue/sticky-label` filter, or return an empty string to remove the label.

= Does the theme collect any data? =

No. Prologue doesn't collect, store or send any data, and it doesn't load anything from other sites.
